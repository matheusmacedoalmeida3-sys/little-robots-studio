# Serviços

Nesta etapa toda a lógica está simulada em `src/store/demo-store.tsx`.
Ao integrar o backend, crie aqui serviços (ex.: `projects.service.ts`, `submissions.service.ts`,
`points.service.ts`) e troque as ações do store por chamadas a eles.
Pontos, avaliações e permissões devem ser validados apenas no servidor.
