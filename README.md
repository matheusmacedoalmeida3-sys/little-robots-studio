# Little Robots Studio

ETAPA OBRIGATÓRIA: ANÁLISE DAS IMAGENS DE REFERÊNCIA

Vou enviar imagens de referência visual que deverão orientar o desenvolvimento da plataforma de robótica infantil.

Antes de começar a implementar a interface, analise cuidadosamente todas as imagens que eu enviar.

Observe principalmente:

Paleta de cores e identidade visual.

Organização do dashboard e da navegação.

Estilo dos cards, banners e imagens.

Tipografia, espaçamentos, bordas e sombras.

Estilo dos ícones, botões e elementos interativos.

Hierarquia visual e comportamento responsivo.

Utilize as imagens como referência principal para definir a direção estética do projeto. Não escolha uma identidade visual definitiva antes de analisá-las.

Não copie cegamente as referências. Adapte sua linguagem visual para uma plataforma de robótica infantil com 100 projetos, envio de fotos, pontos, conquistas e ranking.

Importante: nesta primeira etapa, implemente somente o frontend, com dados demonstrativos e interações simuladas. Não implemente backend, autenticação real, banco de dados ou pagamentos.

Se as imagens ainda não tiverem sido enviadas, aguarde o envio antes de definir o design final. Depois de analisá-las, desenvolva as telas mantendo consistência com a identidade visual identificada.
